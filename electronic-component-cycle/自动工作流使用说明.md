# 电子元器件周期自动分析智能体 - 使用说明

## 🚀 系统架构

我们已经实现了你要的**全自动工作流**，核心架构参考了 `doubao-industry-analysis` 的成熟pipeline设计，分为5层：

```
┌─────────────────────────────────────────────────────────────┐
│  1. 事件发现层  EventDiscovery                              │
│     - 按年份+品类自动生成搜索query                           │
│     - 自动去重，跳过已入库事件                               │
├─────────────────────────────────────────────────────────────┤
│  2. 信息收集层  （对接general_search/seed_finance_search）   │
│     - 多轮搜索收集时间线、价格数据、原因分析                  │
│     - 自动URL去重、内容去重                                 │
├─────────────────────────────────────────────────────────────┤
│  3. 智能分析层                                              │
│     ├─ InformationGrader：自动A/B/C信息分级                 │
│     ├─ RCAAnalyzer：自动根因分析、分类、识别错误传言         │
│     └─ 自动生成对应周期类型的预警模板                        │
├─────────────────────────────────────────────────────────────┤
│  4. 自动校验层                                              │
│     - 自动时序因果校验（原因必须早于结果）                    │
│     - 自动检查字段完整性、价格数据格式                       │
│     - 自动排除市场噪音                                      │
├─────────────────────────────────────────────────────────────┤
│  5. 经验库层  Graphiti时序知识图谱                          │
│     - 自动追加新事件、新案例、新因果关系                     │
│     - 自动更新版本号、统计数据、验证结果                     │
└─────────────────────────────────────────────────────────────┘
```

## 🎯 核心功能：一键自动分析新事件

这是你要的核心功能：**输入一段历史行情描述，自动分析因果、生成经验、写入经验库**

### 使用方法

```python
from auto_cycle_pipeline import AutoCyclePipeline

# 初始化pipeline
pipeline = AutoCyclePipeline("../graphiti/cycle_knowledge_graph.json")

# 一键自动分析！
result = pipeline.auto_analyze_new_event(
    event_description="""
    2018年MLCC涨价事件：2017Q2村田、TDK、太阳诱电砍中低端MLCC产能转车规，
    2017Q3三星停电事故影响3.5%产能，2018Q1国巨华新科涨价20%-100%，
    0402通用MLCC涨幅200%-500%，当时市场传言游资爆炒，事后证明是产能主动调整，
    2018Q3价格见顶后下跌。
    """,
    category="MLCC",
    source="产业事后复盘"
)
```

### 自动完成的工作（不需要人工干预）

✅ **自动提取时间**：从文本中识别"2017Q2"、"2018Q1"等时间，自动转换为标准格式  
✅ **自动提取价格数据**：自动识别"涨幅200%-500%"、"影响3.5%产能"等数字  
✅ **自动信息分级**：根据来源自动打A/B/C可信度标签  
✅ **自动RCA根因分析**：
  - 识别根因：`["产能收缩"]`
  - 识别催化剂：`["停电事故"]`
  - 识别放大器：`[]`
  - 识别错误传言：`["游资爆炒"]`
✅ **自动判断周期类型**：自动分类为「供给收缩型/成本推动型/需求错配型/需求革命型」
✅ **自动生成预警模板**：根据周期类型自动生成3条红/橙/绿预警规则
✅ **自动时序校验**：自动检查所有因果关系的时间顺序，时间倒置的直接标记无效
✅ **自动写入经验库**：新事件、新案例自动追加到知识图谱，自动更新版本号和统计数据

### 供给收缩型自动生成
- 🔴 红色预警：头部厂商关产/转产 + 12个月无新产能 → 12个月内涨价50%+
- 🟢 绿色预警：新产能大规模投放 + 价格连涨4季度 → 6个月内见顶

### 供需错配+黑天鹅型自动生成
- 🔴 红色预警：大客户砍单30%+ 3个月后需求复苏，产能被占 → 6个月内涨价100%+
- 🟠 橙色预警：连续2次5%+产能黑天鹅 + 交期>40周 → 缺货高峰持续3-6个月
- 🟢 绿色预警：需求下滑 + 渠道库存>3个月 → 3个月缓解，6个月降价

### 成本推动型自动生成
- 🔴 红色预警：原材料连涨3个月 + 产能扰动 → 1-2个月原厂涨价10%-30%
- 🟠 橙色预警：日厂交期>16周 + 台厂连涨2波 → 紧缺料涨50%-100%
- 🟢 绿色预警：需求转弱 + 交期缩短 → 1-2季度价格回落

## 🔄 完全自动爬取扩展

现在的pipeline已经把所有分析逻辑都写好了，如果你要实现"自己爬过去10年数据"，只需要在事件发现层加一个循环：

```python
# 全自动爬取所有历史事件（伪代码）
pipeline = AutoCyclePipeline(kg_path)
discovery = EventDiscovery()

# 自动生成所有搜索query
all_queries = discovery.generate_search_queries()  # 10年×8品类×6关键词=480个query

for query in all_queries:
    # 1. 自动搜索
    results = general_search(query)
    # 2. 自动过滤已入库事件
    new_events = discovery.filter_new_events(results, pipeline.updater.kg)
    # 3. 自动分析+自动入库
    for event in new_events:
        pipeline.auto_analyze_new_event(
            event_description=event["content"],
            category=query.split()[1],
            source=event.get("source", "自动搜索")
        )
    time.sleep(1)  # 避免限流
```

这个循环跑完，就自动把过去10年所有品类的涨价事件都分析完、入完库了。
