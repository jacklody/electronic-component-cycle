# 🔬 电子元器件周期智能体

基于2016-2026三轮大周期深度复盘的AI行情分析专家，自动分析因果、自动积累经验、自动预警行情。

## ✨ 核心特性

- 🧠 **自动根因分析**：自动区分根因/催化剂/放大器，自动排除市场噪音
- ⏰ **时序因果校验**：强制"原因早于结果"，杜绝马后炮式因果倒置
- 📊 **A/B/C三级可信度**：官方数据/媒体报道/市场传言自动分级，不把传言当事实
- 🚨 **三级预警机制**：红/橙/绿三级预警，明确告诉你什么时候该备货/去库存/观望
- 📚 **自学习经验库**：每分析一个事件，经验库自动增长，判断越来越准
- 🎛️ **可视化配置**：自带Web配置工具，点点鼠标就能扩展，不用改代码
- 🔄 **双向周期支持**：不仅能识别涨价，还能识别产能过剩、价格战、周期见顶

## 🚀 快速开始

### 1. 开箱即用
```bash
git clone https://github.com/yourname/electronic-component-cycle-agent.git
cd electronic-component-cycle-agent
```

### 2. 一键分析新事件
```python
from scripts.auto_cycle_pipeline import AutoCyclePipeline

pipeline = AutoCyclePipeline("graphiti/cycle_knowledge_graph.json")

# 把你看到的行情新闻喂进去，自动分析
result = pipeline.auto_analyze_new_event(
    event_description="""
    2026Q3 TI宣布全系列模拟芯片涨价15%，
    原因是8寸成熟产能紧张，原材料涨价，
    市场传言又是游资炒作。
    """,
    category="模拟芯片",
    source="TI官方公告"
)

print(result["warning_level"])       # 🔴红色涨价预警
print(result["action_suggestion"])   # 建议逐步建安全库存，预计持续2-4季度
```

    # 自动搜索最近7天的行情新闻
    new_events = search_recent_events(days=7)
    for event in new_events:
        result = pipeline.auto_analyze_new_event(...)
