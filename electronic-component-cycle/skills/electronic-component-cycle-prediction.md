# 电子元器件周期行情预判技能

## 技能触发条件
当用户询问以下问题时自动触发本技能：
- 电子元器件/半导体/芯片涨价/缺货原因分析
- 未来行情走势判断
- 现在是否应该备货/囤货
- 某类元器件（MLCC/MCU/功率器件/存储）价格走势
- 历史涨价周期对比

---

## 核心预判规则（A级，多周期验证）

### 🟢 规则1：供给驱动型涨价预警
**触发特征（满足3条及以上）**：
- [ ] 全球Top3厂商主动宣布减产/关产线/产能转移
- [ ] 行业资本开支增速连续2个季度同比下滑
- [ ] 行业B/B值连续2个月大于1.2
- [ ] 未来12个月内没有头部厂商的大规模新产能投产计划
- [ ] 渠道库存水位低于1.5个月

**预判结论**：
- 概率：85%
- 行情性质：供给驱动型涨价
- 预计持续时间：12-18个月上涨期
- 预计涨幅：通用料号50%-200%，紧缺料号可能更高
- 关键观察指标：新产线建设进度、原厂资本开支变化

**反例排除**：如果只有单一厂商涨价，其他厂商没有跟进，且渠道库存高企，则为"假涨价"，无法持续

---

### 🔴 规则2：周期见顶预警
**触发特征（满足3条及以上）**：
- [ ] 价格已经连续上涨4个季度以上
- [ ] 2家以上头部厂商宣布百亿级大规模扩产计划
- [ ] 渠道库存水位大于3个月
- [ ] 现货市场开始出现抛货现象，价格松动
- [ ] 下游终端需求增速开始下滑

**预判结论**：
- 概率：90%
- 行情阶段：6个月内价格见顶
- 预计跌幅：30%-70%，通用料号可能跌回涨价前
- 去库存时间：18-24个月
- 操作建议：停止高价备货，开始去库存

**反例排除**：如果有新的重大需求增量（如新技术爆发），可能延长周期6-12个月

---

### 🟡 规则3：周期底部预警
**触发特征（满足3条及以上）**：
- [ ] 行业出现大面积亏损，多家厂商发布减产公告
- [ ] 整体产能利用率低于60%
- [ ] 连续2个季度全行业没有新的扩产计划
- [ ] 渠道库存低于1个月，部分料号开始出现交期拉长
- [ ] 现货价格已经跌破现金成本

**预判结论**：
- 概率：80%
- 行情阶段：12个月内将启动新一轮上涨周期
- 操作建议：逐步建立安全库存，锁定低价货源

---

### ⚡ 规则4：黑天鹅事件影响判断
**触发特征**：
- [ ] 主要厂商工厂发生火灾/地震/停电/疫情封控等事故
- [ ] 事故发生时行业供需已经处于紧平衡状态（B/B>1.1）
- [ ] 事故影响全球该品类5%以上产能

**预判结论**：
- 概率：70%
- 影响性质：短期脉冲式上涨，不改变大周期方向
- 持续时间：1-3个月
- 涨幅：20%-50%
- 关键提醒：不要因为黑天鹅事件恐慌性囤货，产能恢复后价格会回落

**反例排除**：如果供需本来就宽松，黑天鹅只会造成1-2周的波动，不会有持续涨价

## 信息可信度判断标准

### A级信息（可作为判断依据）
- 原厂官方公告（涨价函、停产通知、财报）
- 第三方权威数据（TrendForce、Counterpoint、Gartner）
- 多家券商研报交叉验证的结论
- 事后1年以上产业复盘确认的事实

### B级信息（仅作参考，不能单独作为判断依据）
- 当时的财经媒体报道
- 产业链人士访谈、渠道消息
- 单一券商研报观点
- 上市公司投资者关系活动记录

### C级信息（直接排除，不进入逻辑链）
- 自媒体、股吧、微信群传言
- "游资炒作"、"国家要收储"等无实锤消息
- "这次不一样，永远涨价"等情绪性言论
- 任何没有具体来源的"听说"、"据传"

## 常见市场噪音排除清单

每轮周期都会出现但从未被证实的说法，直接排除：
1. ❌ "游资/热钱在爆炒电子元器件" —— 事后证明都是正常库存周期
2. ❌ "这次缺货会永远持续，再也不会降价" —— 每轮顶部都有这个说法
3. ❌ "贸易战/制裁会导致长期缺货" —— 供应链调整能力远超预期
4. ❌ "某家厂商出事了，全行业要缺货一年" —— 单一厂商事故影响不超过3个月
5. ❌ "大家都在抢货，再不下单就没了" —— 典型的销售话术，看实际库存数据

## 标准分析流程（SOP）

1. **第一步：定位周期阶段**
   - 收集当前B/B值、库存水位、产能利用率、价格趋势
   - 对照4条核心规则判断当前在周期的哪个位置

2. **第二步：交叉验证信息**
   - 所有信息按A/B/C三级分类
   - B级信息需要至少2个独立来源交叉验证
   - C级信息直接排除

3. **第三步：区分因果与相关**
   - 检查时间顺序：原因必须发生在结果之前
   - 区分根因（资本开支/产能）、直接诱因（事故/政策）、放大因素（牛鞭效应/囤货）
   - 排除同期发生但不构成因果的事件

4. **第四步：反事实测试**
   - 问自己：如果没有这个事件，价格还会涨吗？
   - 如果答案是"会"，说明这个事件只是放大器，不是根本原因
   - 如果答案是"不会"，才是核心驱动因素

5. **第五步：给出结论**
   - 明确说明判断的置信度
   - 给出关键观察指标，什么信号出现会推翻判断
   - 给出具体的操作建议，不要模棱两可
