📖 前后端数据传递说明

✅ 最简单的方式：不用后端！ 配置完点「💾 下载配置文件」，把下载的 config.json 替换项目根目录下的同名文件，重启pipeline直接生效，完全不用改代码。

🚀 方式二：启动本地服务，点按钮直接保存生效

1. 在项目根目录打开命令行，运行：
python start_config_server.py

2. 刷新这个页面，顶部状态会变成「✅ 已连接本地服务」
3. 配置完点「🚀 直接保存生效」，配置自动写入config.json，不用下载替换，立即生效

📡 前后端通信方式

  • 前端启动时自动请求 http://localhost:8765/api/config 加载现有配置
  • 点保存时POST到 http://localhost:8765/api/save，body是完整的config JSON
  • 后端只有2个接口，代码只有50行，没有任何依赖，Python标准库就能跑
  • 所有配置都存在 config.json，Python代码直接读取，改完立即生效

📁 数据流

前端页面（config-manager.html）
        ↓  GET /api/config 加载配置
        ↓  POST /api/save 保存配置
本地简单服务（start_config_server.py）
        ↓  读写
config.json 配置文件
        ↓  启动时加载
自动分析pipeline（auto_cycle_pipeline.py）
        ↓  使用配置
分析新事件 → 生成预警 → 写入经验库
